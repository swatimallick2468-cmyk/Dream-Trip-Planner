# Dream Trip Planner

## Project Overview

Dream Trip Planner is a Python command-line application that helps users create a simple travel plan.
The user can selects their preferred type of experience, chooses a recommended destination, enters the number of travellers, trip duration and budget.
The program then provides a hotel suggestion, transport information, best season to go, estimated cost and provide day-wise itinerary.

## Features

- Suggest user interest-based destination 
- Allows user to select destination 
- Take the number of travellers from the user
- Allows trip from 1 to 10 days
- Budget input
- Hotel recommendation
- Transport suggestion
- Shows the best season to visit
- Day-wise itinerary
- Final trip summary
- Checks whether the user enters valid information

## Requirements

To run this project, you need:

- Python 3.13 or above
- Visual Studio Code (VS Code)
- Python extension installed in VS Code
- All project files kept in the same folder
- No external Python libraries or APIs are required

## How to Run

1. Install Python 3.13 on your computer.
2. Install Visual Studio Code.
3. Install the Python extension in VS Code.
4. Open the `Dream-Trip-Planner` folder in VS Code.
5. Make sure all the project files are in the same folder.
6. Open `main.py`.
7. Run the program using the Run button in VS Code.

You can also run the program from the VS Code terminal using:

```text
python main.py
