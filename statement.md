# Dream Trip Planner - Project Statement

## Problem Statement

Planning a trip requires selecting a destination, deciding the number of days, estimating the budget, choosing accommodation and planning activities. It takes takes lot of time

Dream Trip Planner is a Python command-line application designed to simplify the basic trip planning process.

## Scope of the Project

The project focuses on planning trips to selected destinations in India.

It provides destination recommendations, hotel suggestions, estimated budget, transport information, best season information and an automatic day-wise itinerary.

The project is designed as a simple command-line application using basic Python concepts.

## Target Users
The target users of this project are:

- Students learning Python
- Beginners who want to plan a simple trip
- People looking for basic travel planning ideas
- Users who want a simple command-line travel planner

## Main Features

- Interest-based destination recommendation
- Destination selection
- 1–10 day trip planning
- Budget calculation
- Hotel recommendation
- Transport suggestion
- Best season information
- Automatic day-wise itinerary
- Final trip summary
- Input validation

## Technologies Used

- Python 3.13
- Visual Studio Code
- Functions and modules
- Lists
- Conditions and loops

No external libraries or APIs are used.

## Testing
This project include a test_project.py file for basic testing to test important main function and it also manually tested using user different input and trips.
